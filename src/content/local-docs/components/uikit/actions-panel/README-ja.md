# ActionsPanel

<!--/GITHUB_BLOCK-->

`ActionsPanel` を使用して、複数のボタンを横並びに表示します。
スペースが足りない場合、収まらないボタンはオーバーフローメニューに追加されます。

## 例

<!--SANDBOX
import type {ActionsPanelProps} from '@gravity-ui/uikit';
import {ActionsPanel} from '@gravity-ui/uikit';

const actions: ActionsPanelProps['actions'] = [
    {
        id: 'action_1',
        button: {
            props: {
                children: 'Action 1',
                onClick: () => console.log('click button action 1'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('click dropdown action 1'),
                text: 'Action 1',
            },
        },
    },
    {
        id: 'action_2',
        button: {
            props: {
                children: 'Action 2',
                onClick: () => console.log('click button action 2'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('click dropdown action 2'),
                text: 'Action 2',
            },
        },
    },
];

export default function () {
    return <ActionsPanel actions={actions} />;
}
SANDBOX-->

## アクションアイコン

アイコンを設定するには、`Button` または `DropdownMenu` のプロパティを使用します。

<!--SANDBOX
import {Files, PencilToSquare, TrashBin} from '@gravity-ui/icons';
import type {ActionsPanelProps} from '@gravity-ui/uikit';
import {ActionsPanel, Flex, Icon} from '@gravity-ui/uikit';

```javascript
const actions: ActionsPanelProps['actions'] = [
    {
        id: 'edit',
        button: {
            props: {
                children: [<Icon key="icon" data={PencilToSquare} />, '編集'],
                onClick: () => console.log('Edit'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('Edit'),
                text: (
                    <Flex alignItems="center" gap={1}>
                        <Icon data={PencilToSquare} />
                        編集
                    </Flex>
                ),
            },
        },
    },
    {
        id: 'copy',
        button: {
            props: {
                children: [<Icon key="icon" data={Files} />, 'コピー'],
                onClick: () => console.log('Copy'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('Copy'),
                text: (
                    <Flex alignItems="center" gap={1}>
                        <Icon data={Files} />
                        コピー
                    </Flex>
                ),
            },
        },
    },
    {
        id: 'delete',
        collapsed: true,
        button: {
            props: {
```

## Properties

| 名前          | 説明                                               |          型           | デフォルト |
| :------------ | :-------------------------------------------------------- | :---------------------: | :-----: |
| actions       | アクションの配列                                          |  `ActionsPanelItem[]`   |         |
| onClose       | オプションの閉じるボタンクリックハンドラー                       |      `() => void`       |         |
| renderNote    | オプションのレンダープロップで、ノートのコンテンツを表示します | `() => React.ReactNode` |         |
| className     | オプションのHTML `class` 属性                           |        `string`         |         |
| noteClassName | オプションのHTML `class` 属性                           |        `string`         |         |
| maxRowActions | 1行あたりの最大アクション数                        |        `number`         |   `4`   |

## ActionsPanelItem:

| 名前      | 説明                                   |                    型                    | デフォルト |
| :-------- | :-------------------------------------------- | :----------------------------------------: | :-----: |
| id        | ユニークなアクションID                              |                  `string`                  |         |
| dropdown  | オーバーフローメニューのドロップダウンアクションの設定 | `{item: DropdownMenuItem; group?: string}` |         |
| button    | ボタンアクションの設定                    |           `{props: ButtonProps}`           |         |
| collapsed | true の場合、アイテムは常にドロップダウン内に表示されます |                 `boolean`                  |         |
