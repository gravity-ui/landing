# ActionsPanel

<!--/GITHUB_BLOCK-->

Use um `ActionsPanel` para renderizar vários botões em uma linha.
Quando não houver espaço suficiente, os botões que não couberem serão adicionados a um menu de overflow.

## Exemplo

<!--SANDBOX
import type {ActionsPanelProps} from '@gravity-ui/uikit';
import {ActionsPanel} from '@gravity-ui/uikit';

const actions: ActionsPanelProps['actions'] = [
    {
        id: 'action_1',
        button: {
            props: {
                children: 'Action 1',
                onClick: () => console.log('click button action 1'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('click dropdown action 1'),
                text: 'Action 1',
            },
        },
    },
    {
        id: 'action_2',
        button: {
            props: {
                children: 'Action 2',
                onClick: () => console.log('click button action 2'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('click dropdown action 2'),
                text: 'Action 2',
            },
        },
    },
];

export default function () {
    return <ActionsPanel actions={actions} />;
}
SANDBOX-->

## Ícones de ação

Use as propriedades `Button` ou `DropdownMenu` para definir ícones.

<!--SANDBOX
import {Files, PencilToSquare, TrashBin} from '@gravity-ui/icons';
import type {ActionsPanelProps} from '@gravity-ui/uikit';
import {ActionsPanel, Flex, Icon} from '@gravity-ui/uikit';

const actions: ActionsPanelProps['actions'] = [
    {
        id: 'edit',
        button: {
            props: {
                children: [<Icon key="icon" data={PencilToSquare} />, 'Edit'],
                onClick: () => console.log('Edit'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('Edit'),
                text: (
                    <Flex alignItems="center" gap={1}>
                        <Icon data={PencilToSquare} />
                        Edit
                    </Flex>
                ),
            },
        },
    },
    {
        id: 'copy',
        button: {
            props: {
                children: [<Icon key="icon" data={Files} />, 'Copy'],
                onClick: () => console.log('Copy'),
            },
        },
        dropdown: {
            item: {
                action: () => console.log('Copy'),
                text: (
                    <Flex alignItems="center" gap={1}>
                        <Icon data={Files} />

    {

## Propriedades

| Nome          | Descrição                                               |          Tipo           | Padrão |
| :------------ | :-------------------------------------------------------- | :---------------------: | :----: |
| actions       | Matriz de ações                                          |  `ActionsPanelItem[]`   |        |
| onClose       | Manipulador de clique opcional do botão fechar                       |      `() => void`       |        |
| renderNote    | Render-prop opcional para exibir o conteúdo de uma nota | `() => React.ReactNode` |        |
| className     | Atributo `class` HTML opcional                           |        `string`         |        |
| noteClassName | Atributo `class` HTML opcional                           |        `string`         |        |
| maxRowActions | Número máximo de ações em uma linha                        |        `number`         |  `4`   |

## ActionsPanelItem:

| Nome      | Descrição                                   |                    Tipo                    | Padrão |
| :-------- | :-------------------------------------------- | :----------------------------------------: | :----: |
| id        | ID de ação exclusivo                              |                  `string`                  |        |
| dropdown  | Configurações para ação de menu suspenso no menu de overflow | `{item: DropdownMenuItem; group?: string}` |        |
| button    | Configurações para ação de botão                    |           `{props: ButtonProps}`           |        |
| collapsed | Se verdadeiro, o item fica sempre dentro do menu suspenso |                 `boolean`                  |        |
