`FileDropZone` ist ein Bereich zur Auswahl von Dateien per Drag & Drop oder über den System-Dateidialog.

```tsx
import {FileDropZone, type DropZoneFileRejection} from '@gravity-ui/uikit';
```

### Grundlegende Verwendung

```tsx
const accept = ['image/*'];
const handleUpdate = (acceptedItems: File[], rejectedItems: DropZoneFileRejection[]) => {
  // Tue etwas mit akzeptierten und abgelehnten Dateien.
};

<FileDropZone accept={accept} onUpdate={handleUpdate} />;
```

### Benutzerdefinierte Texte und Symbole

```tsx
import {DatabaseFill, HeartCrack} from '@gravity-ui/icons';

const accept = ['image/*'];
const handleUpdateAccepted = (files: File[]) => {
  // Tue etwas mit Dateien.
};

<FileDropZone
  accept={accept}
  onUpdateAccepted={handleUpdateAccepted}
  title="Lorem ipsum dolor sit amet"
  description="Duis consequat commodo eros sit"
  buttonText="Hochladen"
  icon={DatabaseFill}
  errorIcon={HeartCrack}
/>;
```

### Benutzerdefiniertes Layout

Das Compound Component Pattern ermöglicht das Rendern eines beliebigen Layouts. Alle Props werden nur an das übergeordnete Element übergeben und über den React Context geteilt, während die Unterkomponenten nur eine `className` empfangen können.

```tsx
const accept = ['image/*'];
const handleUpdateAccepted = (files: File[]) => {
  // Tue etwas mit Dateien.
};

<FileDropZone
  accept={accept}
  onUpdateAccepted={handleUpdateAccepted}
  title="Lorem ipsum dolor sit amet"
  description="Duis consequat commodo eros sit"
  buttonText="Hochladen"
  icon={DatabaseFill}
  errorIcon={HeartCrack}
>
  <div
    style={{
      flexGrow: '1',
      display: 'flex',
      flexDirection: 'row',
      justifyContent: 'space-between',
      alignItems: 'center',
    }}
  >
    <div
      style={{
        display: 'flex',
        flexDirection: 'row',
        alignItems: 'center',
        gap: '32px',
      }}
    >
      <FileDropZone.Icon />
      <div style={{display: 'flex', flexDirection: 'column', alignItems: 'flex-start'}}>
        <FileDropZone.Title />
        <FileDropZone.Description />
      </div>
    </div>
    <div style={{marginInlineStart: '16px'}}>
      <FileDropZone.Button />
    </div>
  </div>

```

### Akzeptierte Dateitypen

`accept` verwendet das Format des HTML `accept`-Attributs. Eine Datei wird akzeptiert, wenn sie mindestens einem Eintrag entspricht:

- ein exakter MIME-Typ, z. B. `image/png`;
- ein Top-Level-Wildcard, z. B. `image/*`;
- eine Dateierweiterung, z. B. `.csv` oder `.md`, die fallunabhängig gegen den Dateinamen abgeglichen wird.

Die gleichen Regeln gelten für per Drag & Drop gezogene Dateien und für im Dialogfeld ausgewählte Dateien.

Während eine Datei nur über die Zone gezogen wird, ist ihr Name noch nicht verfügbar, daher markieren Erweiterungseinträge den Drag nicht als ungültig. Die endgültige Prüfung erfolgt beim Ablegen: Eine Datei mit einem nicht übereinstimmenden Typ wird während des Ziehens hervorgehoben, kann aber dennoch abgelegt und an `onUpdateRejected` übergeben werden. Ein Ziehen ohne Dateien, wie z. B. ausgewählter Text oder ein Link, kann nicht auf die Zone abgelegt werden.

MIME-Einträge werden gegen `File.type` geprüft, das vom Betriebssystem bereitgestellt wird. Es kann für unbekannte Erweiterungen leer sein (`File.type === ''`) oder von dem abweichen, was Sie erwarten: Zum Beispiel meldet Chrome unter Windows `.csv` als `application/vnd.ms-excel`, wenn Excel installiert ist, und `.zip` als `application/x-zip-compressed`. Das Dateidialogfeld filtert nach Erweiterungen, sodass es eine solche Datei anzeigen kann, aber sie wird nach der Auswahl mit `invalid-type` abgelehnt. Um solche Dateien zuverlässig zu akzeptieren, listen Sie die Erweiterung neben dem MIME-Typ auf, z. B. `['text/csv', '.csv']` oder `['image/*', '.heic']`.

Leere und nur aus Leerzeichen bestehende Einträge werden ignoriert. Eine Liste ohne weitere Einträge akzeptiert alle Dateitypen, wie es das HTML `accept`-Attribut tut.

                                                1. **Akzeptierte Dateitypen**
   * `accept`: Zulässige Dateitypen: MIME-Typen, Top-Level-Wildcards und Dateierweiterungen. Eine leere Liste akzeptiert alle Dateitypen. Siehe [Akzeptierte Dateitypen](#accepted-file-types).
   * Typ: `string[]`
   * Standard: `[]`

2. **Ereignisbehandlung für Datei-Updates**
   * `onUpdate`: Ein Callback, der aufgerufen wird, wenn Dateien hinzugefügt werden. Empfängt akzeptierte und abgelehnte Dateien in einem einzigen Aufruf.
   * Typ: `(acceptedItems: File[], rejectedItems: DropZoneFileRejection[]) => void`
   * Standard: -

   * `onUpdateAccepted`: Ein Callback, der aufgerufen wird, wenn akzeptierte Dateien hinzugefügt werden.
   * Typ: `(items: File[]) => void`
   * Standard: -

   * `onUpdateRejected`: Ein Callback, der mit abgelehnten Dateien aufgerufen wird: abgelegte oder ausgewählte Dateien, deren Typ nicht mit `accept` übereinstimmt, und Dateien, die über die erste hinausgehen (im Einzeldatei-Modus).
   * Typ: `(items: DropZoneFileRejection[]) => void`
   * Standard: -

3. **Anzeige und Beschriftung**
   * `title`: Ein Titel, der unter dem Symbol angezeigt wird.
   * Typ: `string`
   * Standard: `"Drag the file here or select it"` (`multiple=false`); `"Drag the files here or select them"` (`multiple=true`)

   * `description`: Eine Beschreibung, die unter dem Titel angezeigt wird.
   * Typ: `string`
   * Standard: -

   * `buttonText`: Eine Beschriftung für den Upload-Button.
   * Typ: `string`
   * Standard: `"Select a file"` (`multiple=false`); `"Select files"` (`multiple=true`)

4. **Symbole**
   * `icon`: Eine benutzerdefinierte Symbolkomponente von `@gravity-ui/icons`. Wenn `null` übergeben wird, wird das Symbol nicht gerendert.
   * Typ: `@gravity-ui/icons/IconData`
   * Standard: -

   * `errorIcon`: Eine benutzerdefinierte Fehler-Symbolkomponente von `@gravity-ui/icons`. Wenn `null` übergeben wird, wird das Fehler-Symbol nicht gerendert.
   * Typ: `@gravity-ui/icons/IconData`
   * Standard: -

5. **Styling und Konfiguration**
   * `className`: Eine CSS-Klasse für das Root-Element.
   * Typ: `string`
   * Standard: -

   * `multiple`: Ein boolescher Wert, der bestimmt, ob mehrere Dateien hochgeladen werden können. Wenn `false`, wird nur eine Datei akzeptiert.
   * Typ: `boolean`
   * Standard: `false`

   * `disabled`: Ein boolescher Wert, der bestimmt, ob der Datei-Upload deaktiviert ist.
   * Typ: `boolean`
   * Standard: -

   * `errorMessage`: Eine Fehlermeldung. Wenn angegeben, werden auch Fehlerstile gerendert.
   * Typ: `string`
   * Standard: -

   * `validationState`: Validierungsstatus. Wenn auf `"invalid"` gesetzt, werden Fehlerstile gerendert.
   * Typ: `"invalid"`
   * Standard: -

6. **Inhalt und Layout**
   * `children`: Benutzerdefinierter Layout-Inhalt. Die zusammengesetzten Unterkomponenten `FileDropZone.Icon`, `Title`, `Description` und `Button` können nur innerhalb von `FileDropZone` verwendet werden.
   * Typ: `React.ReactNode`
   * Standard: -
