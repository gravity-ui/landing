# Toc

<!--/GITHUB_BLOCK-->

`Toc` コンポーネントは、ページの見出しの目次を表示するように設計されており、2つの階層レベルを持つアイテムのセットを表示します。

```tsx
import {Toc} from '@gravity-ui/uikit';
```

## 使用方法

`Toc` は2つの方法で使用できます。

1. アイテムをリンクとして使用する。
2. アイテムを clickable なボタンとして使用する。

最初のオプションを使用するには、各 `Toc` アイテムに `href` プロパティを通じて適切なリンクを提供します。アクティブな `Toc` 要素を制御するために、クリックハンドラーを引き続き使用できます。

これをスキップすると、コンポーネントは別のオプションを使用します。

## プロパティ

| 名前      | 説明                                                                                             |    型     | デフォルト |
| :-------- | :----------------------------------------------------------------------------------------------- | :-------: | :------: |
| className | CSS クラス                                                                                       | `string`  |          |
| items     | 目次要素                                                                                         | `TocItem[]` |          |
| value     | 現在アクティブなアイテム                                                                         | `string`  |          |
| onUpdate  | アイテムクリックハンドラー                                                                       | `Function` |          |
| qa        | `Toc` コンテナの `data-qa` 属性に提供する値                                                      | `string`  |          |

#### TocItem

| 名前    | 説明                                                                                             |        型         | デフォルト |
| :------ | :----------------------------------------------------------------------------------------------- | :---------------: | :------: |
| value   | アイテムの値                                                                                     |      `string`      |          |
| content | 表示するアイテムの内容                                                                           | `React.ReactNode[]` |          |
| href    | 提供された場合にアイテムが変換される `<a>` 要素の `href` プロパティ                                |      `string`      |          |
| items   | 子アイテム                                                                                       |     `TocItem[]`    |          |
