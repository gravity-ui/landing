`Toc` 组件旨在显示页面的目录，即显示具有两个层级结构的条目。

```tsx
import {Toc} from '@gravity-ui/uikit';
```

## 用法

您可以通过两种方式使用 `Toc`：

1.  将条目作为链接。
2.  将条目作为可点击的按钮。

要使用第一种选项，请通过 `href` 属性为每个 `Toc` 条目提供适当的链接。您仍然可以使用点击处理程序来控制活动的 `Toc` 元素。

如果跳过此项，组件将使用其他选项。

## 属性

| 名称      | 描述                                                               |    类型     | 默认值 |
| :-------- | :----------------------------------------------------------------- | :---------: | :-----: |
| className | CSS 类名                                                           |  `string`   |         |
| items     | TOC 元素                                                           | `TocItem[]` |         |
| value     | 当前活动项                                                         |  `string`   |         |
| onUpdate  | 条目点击处理程序                                                   | `Function`  |         |
| qa        | 提供给 `Toc` 容器的 `data-qa` 属性的值                               |  `string`   |         |

#### TocItem

| 名称    | 描述                                                                                             |        类型         | 默认值 |
| :------ | :----------------------------------------------------------------------------------------------- | :-----------------: | :-----: |
| value   | 条目值                                                                                           |      `string`       |         |
| content | 要显示的条目内容                                                                                 | `React.ReactNode[]` |         |
| href    | `<a>` 元素的 `href` 属性，如果提供，条目将转换为该元素                                             |      `string`       |         |
| items   | 子条目                                                                                           |     `TocItem[]`     |         |
