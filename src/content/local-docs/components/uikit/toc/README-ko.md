`Toc` 컴포넌트는 페이지의 목차를 표시하도록 설계되었으며, 계층 구조가 두 개인 항목 집합을 보여줍니다.

```tsx
import {Toc} from '@gravity-ui/uikit';
```

## 사용법

`Toc`은 두 가지 방법으로 사용할 수 있습니다.

1. 링크로 항목 사용
2. 클릭 가능한 버튼으로 항목 사용

첫 번째 옵션을 사용하려면 `href` 속성을 통해 각 `Toc` 항목에 적절한 링크를 제공하세요. 여전히 클릭 핸들러를 사용하여 활성 `Toc` 요소를 제어할 수 있습니다.

이것을 생략하면 컴포넌트는 다른 옵션을 사용합니다.

## 속성

| 이름      | 설명                                                                   |    타입     | 기본값 |
| :-------- | :--------------------------------------------------------------------- | :---------: | :-----: |
| className | CSS 클래스                                                             |  `string`   |         |
| items     | TOC 요소                                                               | `TocItem[]` |         |
| value     | 현재 활성 항목                                                         |  `string`   |         |
| onUpdate  | 항목 클릭 핸들러                                                       | `Function`  |         |
| qa        | `Toc` 컨테이너의 `data-qa` 속성에 제공할 값                            |  `string`   |         |

#### TocItem

| 이름    | 설명                                                                                             |        타입         | 기본값 |
| :------ | :----------------------------------------------------------------------------------------------- | :-----------------: | :-----: |
| value   | 항목 값                                                                                          |      `string`       |         |
| content | 표시할 항목 내용                                                                                 | `React.ReactNode[]` |         |
| href    | 제공되는 경우 항목이 변환될 `<a>` 요소의 `href` 속성                                            |      `string`       |         |
| items   | 하위 항목                                                                                        |     `TocItem[]`     |         |
