# Breadcrumbs

<!--/GITHUB_BLOCK-->

`Breadcrumbs` ist ein Navigationselement, das den aktuellen Speicherort einer Seite in der Hierarchie einer Website anzeigt. Es bietet Links, die es Benutzern ermöglichen, zu höheren Ebenen in der Hierarchie zurückzukehren, was die Navigation durch eine Website mit mehreren Ebenen erleichtert. Breadcrumbs sind besonders nützlich für große Websites und Anwendungen mit einer hierarchischen Seitenstruktur.

```tsx
import {Breadcrumbs} from '@gravity-ui/uikit';
```

### Ereignisse

Verwenden Sie die Eigenschaft `onAction` als Callback, um Klickereignisse auf Elementen zu behandeln.

<!--SANDBOX
import {Box, Breadcrumbs} from '@gravity-ui/uikit';

export default function () {
    return (
        <Box width="100%">
            <Breadcrumbs onAction={(id) => alert(id)}>
                <Breadcrumbs.Item>Region</Breadcrumbs.Item>
                <Breadcrumbs.Item>Country</Breadcrumbs.Item>
                <Breadcrumbs.Item>City</Breadcrumbs.Item>
                <Breadcrumbs.Item>District</Breadcrumbs.Item>
                <Breadcrumbs.Item>Street</Breadcrumbs.Item>
            </Breadcrumbs>
        </Box>
    );
}
SANDBOX-->

<!--GITHUB_BLOCK-->

```jsx
const [currentId, setCurrentId] = React.useState();
const items = [
    {id: 1, label: 'Region'},
    {id: 2, label: 'Country'},
    {id: 3, label: 'City'},
    {id: 4, label: 'District'},
    {id: 5, label: 'Street'},
]
<div>
    <Breadcrumbs onAction={setCurrentId}>
        {items.map((i) => <Breadcrumbs.Item key={i.id}>{i.label}</Breadcrumbs.Item>)}
    </Breadcrumbs>
    <p>You clicked item ID: {currentId}</p>
</div>
```

### Links

In `Breadcrumbs` löst das Klicken auf ein Element normalerweise `onAction` aus. Sie können sie jedoch auch als Links zu anderen Seiten oder Websites verwenden. Um dies zu tun, fügen Sie die Eigenschaft `href` zur Komponente `<Breadcrumbs.Item>` hinzu:

<!--SANDBOX
import {Box, Breadcrumbs} from '@gravity-ui/uikit';

export default function () {
    return (
        <Box width="100%">
            <Breadcrumbs>
                <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>
                <Breadcrumbs.Item href="/components">Components</Breadcrumbs.Item>
                <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
            </Breadcrumbs>
        </Box>
    );
}
SANDBOX-->

```jsx
<Breadcrumbs>
  <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>

  <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
```

### Integration mit Routern

<!--GITHUB_BLOCK-->

#### React Router

```jsx
import {useLinkClickHandler, useHref} from 'react-router';
import {Breadcrumbs, BreadcrumbsItem} from '@gravity-ui/uikit';

function RouterLink({to, ...rest}) {
  const href = useHref(to);
  const onClick = useLinkClickHandler(to);
  return <BreadcrumbsItem {...rest} href={href} onClick={onClick} />;
}
```

```jsx
function Navigation() {
  return (
    <Breadcrumbs itemComponent={RouterLink}>
      <RouterLink to="/">Home</RouterLink>
      <RouterLink to="/components">Components</RouterLink>
      <RouterLink to="/components/breadcrumbs">Breadcrumbs</RouterLink>
    </Breadcrumbs>
  );
}
```

#### Next.js

```jsx
import Link from 'next/link';
import {Breadcrumbs, BreadcrumbsItem} from '@gravity-ui/uikit';

function RouterLink({href, ...rest}) {
  return (
    <Link href={href} passHref legacyBehavior>
      <BreadcrumbsItem {...rest} />;
    </Link>
  );
}

function Navigation() {
  return (
    <Breadcrumbs itemComponent={RouterLink}>
      <RouterLink href="/">Home</RouterLink>
      <RouterLink href="/components">Components</RouterLink>
      <RouterLink href="/components/breadcrumbs">Breadcrumbs</RouterLink>
    </Breadcrumbs>
  );
}
```

#### Tanstack Router

### Landmarks

Wenn Breadcrumbs als Hauptelement der Navigation einer Seite verwendet werden, können sie in einem [Navigations-Landmark](https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/navigation.html) platziert werden. Landmarks helfen Benutzern von assistiven Technologien, wichtige Abschnitte einer Seite schnell zu finden. Um ein Navigations-Landmark zu erstellen, platzieren Sie Breadcrumbs innerhalb eines `<nav>`-Elements mit einem `aria-label`:

<!--SANDBOX
import {Box, Breadcrumbs} from '@gravity-ui/uikit';

export default function () {
    return (
        <Box width="100%">
            <nav aria-label="Breadcrumbs">
                <Breadcrumbs>
                    <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>
                    <Breadcrumbs.Item href="/components">Components</Breadcrumbs.Item>
                    <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
                </Breadcrumbs>
            </nav>
        </Box>
    );
}
SANDBOX-->

## Eigenschaften

| Name             | Beschreibung                                                                  | Typ                                       | Standard |
| :--------------- | :--------------------------------------------------------------------------- | :----------------------------------------- | :------ |
| children         | Breadcrumb-Elemente                                                             | `React.ReactElement<BreadcrumbsItemProps>` |         |
| disabled         | Bestimmt, ob `Breadcrumbs` deaktiviert sind.                               | `boolean`                                  |         |
| showRoot         | Aktiviert oder deaktiviert die immerwährende Anzeige des Root-Elements, wenn die Elemente eingeklappt sind. | `boolean`                                  |         |
| popupPlacement   | Stil des Popups für eingeklappte Elemente.                                           | `PopupPlacement`                           |         |
| popupStyle       | Stil des Popups für eingeklappte Elemente.                                           | `"staircase"`                              |         |
| qa               | `data-qa` HTML-Attribut, das zum Testen verwendet wird                                   | `string`                                   |         |
| separator        | Benutzerdefinierter Trennknoten.                          | `React.ReactNode`                          | "/"     |
| action           | `click` Ereignisbehandlungsroutine.                                                       | `(id: Key) => void`                        |         |
| id               | Eindeutige ID des Elements.                                                         | `string`                                   |         |
| className        | CSS-Klassenname für das Element.                                              | `string`                                   |         |
| style            | Legt den Inline-Stil für das Element fest.                                       | `CSSProperties`                            |         |
| aria-label       | Definiert einen Zeichenfolgenwert, der das aktuelle Element beschriftet.                      | `string`                                   |         |
| aria-labelledby  | Identifiziert das/die Element(e), das/die das aktuelle Element beschriftet.                    | `string`                                   |         |
| aria-describedby | Identifiziert das/die Element(e), das/die das Objekt beschreibt.                          | `string`                                   |         |
| endContent       | Vom Benutzer gerenderter Knoten nach dem letzten Breadcrumb-Element.                             | `React.ReactNode`                          |         |

### BreadcrumbsItemProps

| Name       | Beschreibung                                                               | Typ                               | Standard |
| :--------- | :------------------------------------------------------------------------- | :-------------------------------- | :------- |
| children   | Inhalt der Breadcrumbs.                                                    | `string`                          |          |
| title      | String-Repräsentation des Item-Inhalts.                                    | `string`                          |          |
| aria-label | Barrierefreiheits-Label für das Item.                                      | `string`                          |          |
| href       | URL, die für den Hyperlink verwendet werden soll.                          | `string`                          |          |
| target     | Zielfenster für den Link.                                                  | `React.HTMLAttributeAnchorTarget` |          |
| rel        | Beziehung zwischen der verknüpften Ressource und der aktuellen Seite.      | `string`                          |          |
| disabled   | Ob das BreadcrumbsItem deaktiviert ist.                                    | `boolean`                         |          |
