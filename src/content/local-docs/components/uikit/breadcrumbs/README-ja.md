# Breadcrumbs

<!--/GITHUB_BLOCK-->

`Breadcrumbs` は、ウェブサイトの階層における現在のページの位置を示すナビゲーション要素です。階層の上位レベルに戻るためのリンクを提供し、複数の階層を持つウェブサイトでのナビゲーションを容易にします。Breadcrumbs は、特に大規模なウェブサイトや階層ベースのページ構造を持つアプリケーションで役立ちます。

```tsx
import {Breadcrumbs} from '@gravity-ui/uikit';
```

### イベント

`onAction` プロパティをコールバックとして使用し、アイテムのクリックイベントを処理します。

<!--SANDBOX

    return (
        <Box width="100%">
            <Breadcrumbs onAction={(id) => alert(id)}>
                <Breadcrumbs.Item>Region</Breadcrumbs.Item>
                <Breadcrumbs.Item>Country</Breadcrumbs.Item>
                <Breadcrumbs.Item>City</Breadcrumbs.Item>
                <Breadcrumbs.Item>District</Breadcrumbs.Item>
                <Breadcrumbs.Item>Street</Breadcrumbs.Item>
            </Breadcrumbs>
        </Box>
    );
}
SANDBOX-->

<!--GITHUB_BLOCK-->

```jsx
const [currentId, setCurrentId] = React.useState();
const items = [
    {id: 1, label: 'Region'},
    {id: 2, label: 'Country'},
    {id: 3, label: 'City'},
    {id: 4, label: 'District'},
    {id: 5, label: 'Street'},
]
<div>
    <Breadcrumbs onAction={setCurrentId}>
        {items.map((i) => <Breadcrumbs.Item key={i.id}>{i.label}</Breadcrumbs.Item>)}
    </Breadcrumbs>
    <p>You clicked item ID: {currentId}</p>
</div>
```

### リンク

`Breadcrumbs` では、通常、アイテムをクリックすると `onAction` がトリガーされます。しかし、他のページやウェブサイトへのリンクとしても使用できます。これを行うには、`<Breadcrumbs.Item>` コンポーネントに `href` プロパティを追加します。

<!--SANDBOX
import {Box, Breadcrumbs} from '@gravity-ui/uikit';

export default function () {
    return (
        <Box width="100%">
            <Breadcrumbs>
                <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>
                <Breadcrumbs.Item href="/components">Components</Breadcrumbs.Item>
                <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
            </Breadcrumbs>
        </Box>
    );
}
SANDBOX-->

<!--GITHUB_BLOCK-->

```jsx
<Breadcrumbs>
  <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>
  <Breadcrumbs.Item href="/components">Components</Breadcrumbs.Item>
  <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
</Breadcrumbs>
```

### ルーターとの統合

<!--GITHUB_BLOCK-->

#### React Router

```jsx
import {useLinkClickHandler, useHref} from 'react-router';
import {Breadcrumbs, BreadcrumbsItem} from '@gravity-ui/uikit';

function RouterLink({to, ...rest}) {
  const href = useHref(to);
  const onClick = useLinkClickHandler(to);
  return <BreadcrumbsItem {...rest} href={href} onClick={onClick} />;
}

function Navigation() {
  return (
    <Breadcrumbs itemComponent={RouterLink}>
      <RouterLink to="/">Home</RouterLink>
      <RouterLink to="/components">Components</RouterLink>
      <RouterLink to="/components/breadcrumbs">Breadcrumbs</RouterLink>
    </Breadcrumbs>
  );
}
```

#### Next.js

```jsx
import Link from 'next/link';
import {Breadcrumbs, BreadcrumbsItem} from '@gravity-ui/uikit';

function RouterLink({href, ...rest}) {
  return (
    <Link href={href} passHref legacyBehavior>
      <BreadcrumbsItem {...rest} />;
    </Link>
  );
}

function Navigation() {
  return (
    <Breadcrumbs itemComponent={RouterLink}>
      <RouterLink href="/">Home</RouterLink>
      <RouterLink href="/components">Components</RouterLink>
      <RouterLink href="/components/breadcrumbs">Breadcrumbs</RouterLink>
    </Breadcrumbs>
  );
}
```

#### Tanstack Router

### ランドマーク

パンくずリストがページのメインナビゲーション要素として使用される場合、[ナビゲーションランドマーク](https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/navigation.html) に配置できます。ランドマークは、支援技術のユーザーがページの主要なセクションをすばやく見つけるのに役立ちます。ナビゲーションランドマークを作成するには、パンくずリストを `aria-label` を持つ `<nav>` 要素内に配置します。

<!--SANDBOX
import {Box, Breadcrumbs} from '@gravity-ui/uikit';

export default function () {
    return (
        <Box width="100%">
            <nav aria-label="Breadcrumbs">
                <Breadcrumbs>
                    <Breadcrumbs.Item href="/">Home</Breadcrumbs.Item>
                    <Breadcrumbs.Item href="/components">Components</Breadcrumbs.Item>
                    <Breadcrumbs.Item href="/components/uikit/breadcrumbs">Breadcrumbs</Breadcrumbs.Item>
                </Breadcrumbs>
            </nav>
        </Box>
    );
}
SANDBOX-->

<!--GITHUB_BLOCK-->

```jsx
<nav aria-label="Breadcrumbs">
  <Breadcrumbs>
```

## プロパティ

| 名前             | 説明                                                                  | タイプ                                       | デフォルト |
| :--------------- | :--------------------------------------------------------------------------- | :----------------------------------------- | :------ |
| children         | パンくずリストのアイテム                                                             | `React.ReactElement<BreadcrumbsItemProps>` |         |
| disabled         | `Breadcrumbs` が無効かどうかを決定します。                               | `boolean`                                  |         |
| showRoot         | アイテムが折りたたまれた場合に、常にルートアイテムを表示するかどうかを有効または無効にします。 | `boolean`                                  |         |
| popupPlacement   | 折りたたまれたアイテムのポップアップのスタイル。                                           | `PopupPlacement`                           |         |
| popupStyle       | 折りたたまれたアイテムのポップアップのスタイル。                                           | `"staircase"`                              |         |
| qa               | `data-qa` HTML 属性、テストに使用されます                                   | `string`                                   |         |
| separator        | カスタムセパレーターノード。                                                       | `React.ReactNode`                          | "/"     |
| action           | `click` イベントハンドラー。                                                       | `(id: Key) => void`                        |         |
| id               | 要素の一意の ID。                                                         | `string`                                   |         |
| className        | 要素の CSS クラス名。                                              | `string`                                   |         |
| style            | 要素のインラインスタイルを設定します。                                       | `CSSProperties`                            |         |
| aria-label       | 現在の要素をラベル付けする文字列値を定義します。                      | `string`                                   |         |
| aria-labelledby  | 現在の要素をラベル付けする要素を識別します。                    | `string`                                   |         |
| aria-describedby | オブジェクトを説明する要素を識別します。                          | `string`                                   |         |
| endContent       | 最後のパンくずリストアイテムの後にレンダリングされるユーザーのノード。                             | `React.ReactNode`                          |         |

### BreadcrumbsItemProps

| 名前       | 説明                                                           | タイプ                              | デフォルト |
| :--------- | :------------------------------------------------------------- | :-------------------------------- | :------ |
| children   | パンくずリストの内容。                                         | `string`                          |         |
| title      | アイテムの内容の文字列表現。                                   | `string`                          |         |
| aria-label | アイテムのアクセシビリティラベル。                             | `string`                          |         |
| href       | ハイパーリンクに使用するURL。                                  | `string`                          |         |
| target     | リンクのターゲットウィンドウ。                                 | `React.HTMLAttributeAnchorTarget` |         |
| rel        | リンクされたリソースと現在のページの関係。                     | `string`                          |         |
| disabled   | BreadcrumbsItemが無効かどうか。                                | `boolean`                         |         |
